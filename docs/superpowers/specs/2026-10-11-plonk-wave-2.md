# Plonk: second wave (parity with WorldGuessr's player features)

Date: 2026-10-11. Builds on `2026-10-11-plonk-multiplayer.md`; where the two differ, this one wins.

## What was asked

Neel: "the place ur pin map needs to be more detailed like geoguessr so they can pinpoint", then "Add exit buttons, streaks like country and stuff, basically EVERYTHING that world guessr has (look up) build it".

I read WorldGuessr's own feature documentation (its `spec-claude/` folder). Scope below is my call.

**In:** exit button; detailed pin map; country streak; hints; country maps; units; health-based ranked duels and leagues; XP and levels; leaderboards; public profiles; game history with replay map; friends and party invites; match chat and reactions; first-visit intro; username change.

**Out:** community map maker, translations, mobile apps, ads/shop, moderation and ban tooling, forum/Discord sign-on, sounds.

## Rules and numbers

- **XP:** `round(score / 50)` per round (max 100) for singleplayer, daily, unranked and team games; 20 per correct country in a streak; none for party or ranked. Hinted rounds earn XP on their halved score.
- **Level:** `floor(sqrt(xp / 250)) + 1`.
- **League** from rating: Bronze below 1100, Silver 1100 to 1299, Gold 1300 to 1499, Platinum 1500 to 1699, Diamond 1700 and up.
- **Hint** (singleplayer and daily only): draws a circle on the pin map that contains the place; radius is `scaleKm / 12`, centre offset from the place by a random distance under 70% of the radius. Using it halves that round's score (rounded down).
- **Country streak:** singleplayer, world map, mode and time as chosen. Each round the player clicks a country; right adds 1 to the streak and loads the next place, wrong ends the run and shows the right country. The clicked country is found in the browser with `@rapideditor/country-coder` at territory level, which is how the dataset's country codes were made. Best streak is saved to the account.
- **Country maps:** any country or territory with at least 40 places in the dataset can be chosen as a singleplayer or party map. Map id is `country:XX`. Scale is the diagonal of its places.
- **Ranked duel = health.** Both players start at 5000 health. Each round the lower scorer loses the difference between the two scores. The match ends when a player's health reaches 0, or after 10 rounds, when higher health wins (equal is a draw). `settings.rounds` is 10 for ranked, and the resolver posts 10 places.
- **Units:** kilometres or miles, a browser setting; the server always stores kilometres.
- **Pin map:** OpenFreeMap `liberty` style in both colour schemes (street names, roads, places), zoom to level 19, plus and minus buttons, and a size control with three sizes that the map remembers.

## API changes

Envelope and conventions as before. `MapId` now also allows `country:XX` (two uppercase letters) everywhere a map id is accepted.

### `GET /api/account`

`account` gains `xp: number`, `level: number`, `league: string`, `bestStreak: number`. Each `recentGames` entry gains `id: string`.

### `POST /api/games`

- Round entries gain optional `lng`, `lat` (the place), `guessLng`, `guessLat` (null when no guess) and `hinted: boolean`. The server stores them for the history view. It does not re-score.
- Streak runs: body `{ kind: 'streak', streak: number /* 0..500 */, seed: string }` → `{ bestStreak: number, xpEarned: number }`.
- Replies for normal games gain `xpEarned: number`.

### `GET /api/games?id=<gameId>` (owner only)

```ts
{ id, playedAt, map, mode, timeLimit, daily: string | null, score, maxScore,
  rounds: Array<{ country: string; distanceKm: number | null; score: number; hinted: boolean;
                  lng: number | null; lat: number | null; guessLng: number | null; guessLat: number | null }> }
```

### `api/social.ts` (new; the eighth function)

`GET /api/social?leaderboard=rating|xp|streak` (no session needed):
```ts
{ board: 'rating' | 'xp' | 'streak',
  entries: Array<{ rank: number; username: string; value: number; level: number; league: string }>,  // top 50
  you: { rank: number; value: number } | null }
```

`GET /api/social?profile=<username>` (no session needed):
```ts
{ username, joinedAt: string, xp, level, rating, league, ratedGames, gamesPlayed, bestStreak,
  recentGames: RecentGame[] }   // 404 envelope when there is no such player
```

`GET /api/social?friends=1` (session):
```ts
{ friends: Array<{ username: string; level: number; league: string; party: string | null /* code of a lobby they are in */ }>,
  incoming: string[], outgoing: string[],
  invites: Array<{ from: string; code: string }> }   // party invites from the last 10 minutes
```

`POST /api/social` (session), body `{ action, ... }`:

| action | fields | notes |
|---|---|---|
| `request` | `username` | max 100 friends; a request to someone who already asked you makes you friends |
| `accept`, `decline`, `remove` | `username` | |
| `invite` | `username`, `code` | friends only; the inviter must be in that lobby |
| `rename` | `username` | same rules as sign-up; once per 30 days |

Each replies with the same shape as `GET ?friends=1`, except `rename`, which replies `{ username }`.

### `api/match.ts`

- `players[]` gains `health: number | null` (ranked only).
- `MatchState` gains `chat: Array<{ id: number; username: string; text: string | null; emote: string | null; at: string }>`: the last 30 entries.
- New actions: `{ action: 'chat', matchId, text }` (1 to 200 characters, one per second per player, a short built-in word list masked with asterisks) and `{ action: 'emote', matchId, emote: 'gg' | 'nice' | 'wow' | 'oof' | 'close' | 'hm' }`. Both reply with `MatchState`.
- At the end of an `unranked` or `team` match each player is credited XP by the rule above.

## Interface

- **Exit:** an Exit button in the round HUD of every game. A singleplayer game in progress asks once before leaving; a match exit sends `leave`.
- **Sidebar additions:** Country streak (under Singleplayer), Leaderboards, Friends. Friends shows a count badge when there are incoming requests or invites.
- **Singleplayer pane:** map choice becomes World, the three regions, and a searchable country list; a Hint button during play.
- **Account pane:** level and XP with progress to the next level, league and rating, best streak, units setting, rename, and recent games that open a history view (round table and a map with each round's place and guess).
- **Profile:** `?user=<name>` opens a read-only profile; usernames in leaderboards, lobbies and standings link to it.
- **Matches:** health bars in ranked; a chat panel with the six reactions as buttons.
- **First visit:** a dismissible three-line introduction on the home pane, remembered in the browser.
