# Plonk: fourth wave (closing the remaining gaps against WorldGuessr)

Date: 2026-10-11. Builds on the earlier specs; where they differ, this one wins.

## Why

After wave 3 a goal check listed what still separates Plonk from WorldGuessr or was left unverified: no skip for a place that cannot load, no moderation, no translations, no app to install, no sounds, no joining a public game under way, scores accepted as the browser reports them, and nothing in the product itself that keeps Google usage inside the free allowance.

## 1. Skip a place that will not load (browser only)

When a round's view fails to load in singleplayer, daily or streak, the notice offers "Try again" and "Skip this place". Skip replaces the place with the next spare and scores nothing for the lost one; the round count is unchanged. In a match a player whose view fails can still guess, as now.

## 2. Joining a public unranked game under way

- A player who queues for `unranked` while a public game still has at least two rounds left to start, and fewer than 8 players, is added to that game instead of waiting. They play from the next round and score 0 for the rounds they missed.
- `QueueState.matchId` is set straight away in that case. Nothing else in the contract changes.

## 3. Moderation

- Moderators are the accounts named in the `MODERATORS` environment variable (comma-separated usernames, compared in lower case).
- `GET /api/account`: `account` gains `moderator: boolean`.
- Players can be reported as well as maps: `POST /api/social` `{ action: 'report', username, reason }` (reason up to 200 characters, one report per reporter per player, a newer one replaces it) → `{ reported: true }`.
- `GET /api/social?moderation=1` (moderators only, 403 otherwise):
```ts
{ maps: Array<{ slug: string; name: string; maker: string; reports: number; reasons: string[] /* newest first, up to 10 */ }>,
  players: Array<{ username: string; reports: number; reasons: string[]; banned: boolean }> }
```
- `POST /api/social` (moderators only): `{ action: 'moderate', target: 'map', slug, decision: 'remove' | 'dismiss' }` and `{ action: 'moderate', target: 'player', username, decision: 'ban' | 'unban' | 'dismiss' }` → the same shape as `?moderation=1`. `remove` deletes the map; `dismiss` clears its reports; `ban` sets the account banned.
- A banned account can still sign in and play alone, but every online action (queue, party, chat, friends, making or editing maps) answers 403 "This account is banned from online play.", its maps are hidden from lists, and it is left out of leaderboards. `account` gains `banned: boolean`.
- Browser: a Moderation pane in the sidebar for moderators only; a Report control on profiles and in match standings; a clear banned notice on online panes.

## 4. Keeping Google inside the free allowance

- `POST /api/daily` `{ action: 'viewer' }` (no session needed) → `{ google: boolean, usedToday: number, limit: number }`. The server counts Google viewers per UTC day and answers `google: false` once the day's limit is reached. The limit is the `GOOGLE_VIEWERS_PER_DAY` environment variable, default 150 (about 4,650 a month against Google's 5,000 free).
- The browser asks before it creates a Google Street View viewer (once per game or match, since one viewer serves a whole game). On `google: false`, or if the request fails, it uses the Panoramax fallback for that game.
- This protects against ordinary traffic. It does not replace the quota cap in the Google Cloud console, which is the only hard stop.

## 5. Sounds (browser only)

Short synthesized sounds, no audio files: pin placed, guess sent, round result (pitch follows the score), the last five seconds of a timer, match found, chat message. A Sound setting on the account pane (on by default, remembered in the browser), honoured everywhere. Nothing plays before the first user gesture.

## 6. Installable app (browser only)

A web app manifest with name, colours and icons, and a service worker that caches the app shell only (never API replies, imagery or map tiles), so Plonk can be installed to a phone's home screen or a desktop and opens full-screen. This is the stand-in for WorldGuessr's mobile apps. An "Install Plonk" control appears where the browser allows it. The security policy in `vercel.json` may need `worker-src 'self'` and `manifest-src 'self'`; say so if it does.

## 7. Languages (browser only)

English, Spanish, French, German and Russian, the five WorldGuessr ships. Every interface string moves to a catalog; the language follows the browser, can be changed on the account pane, is remembered, and can be forced with `?lang=xx`. Country names follow the language (`Intl.DisplayNames`). Messages that come from the server stay in English. The translations are machine-written and have not been checked by native speakers; the README says so.

## 8. Tutorial (browser only)

The first-visit card gains "Play the tutorial": a two-round guided game on fixed, recognisable places with short coach marks (look around, move, open the map, place the pin, guess, read the result). It can be replayed from the account pane and never counts for stats.

## 9. Score checking (server only)

`POST /api/games` no longer stores scores as sent. For each round that carries the place and guess coordinates the server recomputes distance and score with the game's formula and the map's scale (`scaleKm`, a new optional field on the request, 100 to 20000; the world constant when the map is `world` or the field is absent), halves it when `hinted`, and stores its own numbers. A round without coordinates is accepted only with no guess and a score of 0. This stops made-up scores; it cannot stop a player who reads the answer out of their own browser, which no browser-rendered game can.

## Testing

As before: tests first, hermetic browser tests, and the live scripts extended: `e2e-live/two-players.mjs` gains a 2v2 run with four browsers, and `e2e-live/features.mjs` gains the viewer budget, a language switch, a report and (with a moderator account supplied by environment variables) the moderation pane.
